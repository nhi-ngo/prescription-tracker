# **Prescription Authorization Tracker**

A full-stack healthcare workflow application that simulates prescription authorization management similar to prior authorization systems used in healthcare operations. The app allows users to create, view, and update authorization requests for patient medications in real time.

Built to demonstrate full-stack engineering skills including REST API design, database integration, automated testing, and modern frontend development.

# **Live Demo**

- Frontend: <https://prescription-tracker.vercel.app/>
- Backend: <https://prescription-tracker-yczj.onrender.com/>

# **Tech**

- Frontend: React (Vite), JavaScript, Axios
- Backend: Node.js, Express.js, REST API architecture
- Database: PostgreSQL (Neon / Supabase)
- Testing: Jest, Supertest
- Deployment: Vercel (frontend), Render (backend)

# **Features**

- Create prescription authorization requests
- View all patient medication requests
- Update authorization status (Pending / Approved / Denied)
- RESTful API with full CRUD operations
- PostgreSQL database integration
- Automated API testing
